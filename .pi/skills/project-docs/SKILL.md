# 项目文档库

本 skill 是文档库的总入口。文档采用 **结构即导航**：先读地图，按需下钻。

## 第一步
开始任何工作前：`read docs/current-state.md`

## 地图
- 完整地图与开发流：`docs/README.md`
- 系统总览（四层架构）：`docs/architecture/overview.md`
- 任务格式与状态：`docs/tasks/README.md`
- PRD 格式：`docs/prds/README.md`

## 原则
不要一次性加载所有文档。先读 `docs/README.md` 的地图，再下钻到具体领域的 README，最后读具体文件。
