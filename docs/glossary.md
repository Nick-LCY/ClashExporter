# 词汇表

统一人与 AI 沟通时对项目术语的理解。每条一个术语：「词 — 在本项目中的解释」。

## 格式
- **术语** — 在本项目中的含义。

## 清单
- **账本** — exporter 内存中按「设备 × 站点 × 节点」分组保存的流量累计状态，是所有导出指标的唯一数据源。
- **增量归账** — 把每条连接「本轮累计值减上轮累计值」的差值累加进账本；连接首次出现时全量计入，计数器回退时增量记 0 而不产生负值。
- **淘汰** — 某组合连续 24 小时（可调）没有新增字节时停止导出其序列，账本数据保留不清零。
- **重锚** — 被淘汰的组合再次产生流量时恢复导出，且恢复后第一次导出的值恰好等于上次导出的值，使 Prometheus 端的 `increase()` 不丢数。
- **fake-ip** — mihomo 的 DNS 劫持方案，返回 `198.18.0.0/15` 保留段内的假 IP；本项目把该段的 IP 字面量站点一律归入 `unresolved` 桶。
- **旁路由** — 部署在局域网内、不接管全网默认路由的网关设备；本项目中 NanoPi R2S 承担此角色，客户端网关指向它，连接的 `sourceIP` 即客户端真实 IP。
- **对账值** — 与核心计数器独立命名的全局累计字节数，取「本轮 API 值与历史最大值的较大者」，用于交叉校验核心指标没有漏记或重复计入。
- **unresolved 桶** — 站点标签无法判定时归入的统一占位标签，覆盖 `host` 缺失、`host` 为 IP 字面量（含 fake-ip 段）两种情况。
