# 架构决策记录（ADR）

每个重要架构决策一个文件，命名 `NNNN-短标题.md`（如 `0001-采用文档驱动开发.md`）。

## 模板

```
# NNNN. 标题

- 日期：
- 状态：提议 | 已接受 | 已废弃
- 背景：（为什么需要这个决策）
- 决策：（决定了什么）
- 影响：（带来的后果）
```
